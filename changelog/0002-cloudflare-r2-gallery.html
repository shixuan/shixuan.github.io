CHANGELOG 0002 — Cloudflare R2 个人相册

Context

想给博客加个相册，几个硬约束：不要用第三方图床（容易跑路、限速、加广告）、不要自己运维服务器、管理后台必须有访问控制、要支持 lazy load + lightbox + 中英 caption。GitHub Pages 是纯静态，做不了上传/删除；普通图床又走不通后台。落地方案是三层架构，Cloudflare 把动态层和存储一起承包：

R2 不暴露 URL，所有图片走 Worker 代理，加长期缓存头。前端代码继续在 Hexo 里写，跟博客其他页面共用同一套构建。

具体的实现细节（Worker 单域名路由、R2 list 分页、原地替换 + cache-bust、lightGallery v2 灯箱、caption metadata LRU 缓存与批量预取、cache 命中与 UI 渲染时序的耦合陷阱、各层 cache 的边界、blur-up backdrop、Workers AI 翻译、浏览器端缩略图生成、Hexo marked 注入 <link> 的 workaround 等）见博客文章：Cloudflare R2 个人相册方案。
